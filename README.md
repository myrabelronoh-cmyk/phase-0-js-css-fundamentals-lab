# Ronoh's Portfolio

A responsive single-page portfolio showcasing my web development skills, learning projects, and contact links.

**Live demo:** https://myrabelronoh-cmyk.github.io/phase-0-js-css-fundamentals-lab/

## Features

- About section with a short introduction and initials avatar
- Skills rendered from a JavaScript array
- Project cards rendered from an array of project objects
- Contact links for email and GitHub
- Responsive layout for desktop and mobile screens
- Plain HTML, CSS, and JavaScript with separate source files

## Files

- `index.html` - page structure and content sections
- `style.css` - responsive page styling
- `script.js` - skills and project data with rendering loops
